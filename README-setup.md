# SUI 텔레그램 알림 — 설치 가이드

폰 어디서든 SUI 매수/익절 신호를 텔레그램으로 받습니다. GitHub이 30분마다 대신 SUI를 확인하고, 신호가 바뀔 때만 알림을 보냅니다. 서버도, 내 PC도 켜둘 필요 없습니다. 계좌 권한은 전혀 사용하지 않습니다(시세만 읽고 메시지만 보냄).

## 준비물 (이미 손에 쥔 것)
- 텔레그램 봇 토큰 (`1234567890:AA...`)
- 채팅 ID (숫자)

---

## 1. 레포에 파일 두 개 올리기

레포(새로 만들거나 기존 것) 최상단에 이렇게 배치합니다:

```
레포/
├─ watcher.js                     ← 그대로 업로드
└─ .github/
   └─ workflows/
      └─ sui-alert.yml            ← sui-alert.yml 을 이 경로/이름으로 업로드
```

- `watcher.js` 는 최상단에.
- `sui-alert.yml` 은 반드시 **`.github/workflows/`** 폴더 안에 넣어야 GitHub이 인식합니다. (웹에서 `Add file → Create new file` 로 `.github/workflows/sui-alert.yml` 이라고 경로째 타이핑하면 폴더가 자동 생성됩니다.)

> 비공개(Private) 레포로 만들어도 무료 사용량 안에서 충분히 돌아갑니다. 토큰을 다루니 Private 권장.

---

## 2. 시크릿(비밀값) 등록 — 토큰은 코드에 절대 넣지 않기

레포 페이지에서:

**Settings → Secrets and variables → Actions → New repository secret**

두 개를 각각 등록합니다 (이름을 정확히 이대로):

| Name (이름) | Value (값) |
|---|---|
| `TELEGRAM_TOKEN` | 봇 토큰 붙여넣기 |
| `TELEGRAM_CHAT_ID` | 채팅 ID 숫자 붙여넣기 |

이렇게 넣으면 코드나 로그에 값이 노출되지 않습니다.

---

## 3. 동작 확인

**Actions 탭 → 왼쪽에서 "SUI Alert" → 오른쪽 "Run workflow" 버튼**으로 즉시 한 번 실행해봅니다.

- 실행 로그에 `상태 null -> fire/buy/sell/wait ...` 가 찍히면 정상.
- 지금이 매수/익절 상태면 텔레그램으로 메시지가 옵니다.
- 지금이 `wait`(대기)면 메시지는 안 옵니다(정상 — 대기 상태는 알리지 않음). 상태가 매수/익절로 바뀌는 순간부터 알림이 시작됩니다.

이후로는 30분마다 자동 실행됩니다. 손댈 것 없습니다.

---

## 알아둘 점

- **알림은 "상태가 바뀔 때만" 옵니다.** 같은 신호가 계속되면 30분마다 도배하지 않습니다. 대기→매수, 매수→익절 처럼 바뀔 때 한 번씩.
- **간격 지연**: GitHub 무료 스케줄은 부하에 따라 정시보다 몇 분 밀릴 수 있습니다. 하루 단위 스윙엔 문제없습니다.
- **판단 기준**: SUI가 자기 1년 가격 범위에서 하위(쌈)면 매수, 상위(비쌈)면 익절. 평단과 무관한 시장 가격 기준.
- **이건 신호일 뿐입니다.** 매매는 알림 보고 직접. 손절 없는 매집이면 종목당 상한과 "잃어도 되는 자금" 원칙을 반드시 지키세요. 레버리지와 병행 금지.
- **바이낸스 접속**: GitHub 서버(미국)에서 바이낸스 시세를 받습니다. 성건님 폰/PC 환경과 무관하게 돌아갑니다.

## 나중에 조이고 싶으면
- 매수/익절 임계값(하위 15%/30%, 상위 70% 등)은 `watcher.js` 의 `signal()` 함수 안 숫자만 바꾸면 됩니다.
- SOL 등 다른 코인을 추가하거나, 알림 간격을 바꾸는 것도 쉽습니다. 필요할 때 말씀 주세요.
